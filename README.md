 # SmartTrack Backend
 Backend service for the SmartTrack task manager, built with Spring Boot and Maven.

## Tech Stack
- Java
- Spring Boot
- Maven
- Docker

## Run locally
./mvnw spring-boot:run

## Run tests
./mvnw test

## Run with Docker
docker build -t smarttrack-backend .
docker run -p 8080:8080 smarttrack-backend
